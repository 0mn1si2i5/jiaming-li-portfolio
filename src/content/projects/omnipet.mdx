## Product problem

A convincing generated image is not yet a desktop pet. Identity must survive multiple actions and directions, frames need compatible structure and transparency, and the final package must remain installable after the production context is removed. OmniPet treats that gap as a product workflow rather than a single prompt.

## Engine capability

OmniPet is an open-source Python engine and CLI for sprite v2 production. Its bounded workflow keeps failed work visible instead of retrying automatically, pauses for explicit review, and can repair a selected job while preserving unaffected upstream work.

Manifest-driven projects make adding a pet repeatable: the manifest defines identity, sprite requirements, and release inputs. To add behavior, maintainers extend action definitions in the engine's versioned contract; creators can then run `pet validate`, `package --check`, `release export`, and `release verify` as separate steps. This is code-and-manifest extensibility, not a runtime plug-in system. The current engine supports one allowlisted built-in image provider and does not expose arbitrary provider or model configuration.

## 产品问题

一张令人信服的生成图还不是桌宠。角色身份需要跨越多种动作与方向，各帧要具备兼容的结构和透明度，最终安装包也必须在脱离生产上下文后继续成立。OmniPet 将这段差距设计成产品工作流，而不是一次提示词调用。

## 引擎能力

OmniPet 是面向 sprite v2 生产的开源 Python 引擎与 CLI。它以有界工作流保留失败结果而不自动重试，在关键节点暂停并等待明确审查，也能修复指定任务而保留不受影响的上游成果。

清单驱动让新增桌宠成为可重复流程：清单声明身份、精灵要求与发布输入。若要增加行为，维护者需要在带版本的引擎契约中扩展动作定义；创作者随后可分别运行 `pet validate`、`package --check`、`release export` 与 `release verify`。这是一种通过代码与清单实现的扩展方式，并非运行时插件系统。当前引擎仅支持一个白名单内置图像 provider，不开放任意 provider 或模型配置。

## User value

Creators can move from uncertain imagery to an installable release through explicit review points, repair only the work that needs attention, and check the package before publication. Export and independent verification keep generation credentials and production context out of the public handoff.

## Public result

SuShi v1.0.1 is the current installable sprite v2 example in the public OmniPets catalog. It demonstrates the intended separation: visitors receive a documented, licensed, verifiable pet release, while production context stays with its creator. OmniPet remains Alpha software; interfaces may change, generated results still require review, and a broader community contribution workflow is not presented as shipped.

</section>

<section lang="zh-CN" data-locale-content="zh">

## 用户价值

创作者可以通过明确的审查节点，把不确定的生成图推进为可安装发布；只修复需要调整的部分，并在发布前检查安装包。导出与独立验证让生成凭据和生产上下文留在公开交付之外。

## 公开结果

SuShi v1.0.1 是 OmniPets 公共目录中当前可安装的 sprite v2 示例。它验证了这套分离：访客获得带说明、许可且可验证的桌宠发布，生产上下文则保留在创作者一侧。OmniPet 仍处于 Alpha 阶段，接口可能变化，生成结果仍需检查；更广泛的社区贡献工作流不会被描述为已交付功能。
