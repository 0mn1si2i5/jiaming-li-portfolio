## Product problem

A convincing generated image is not yet a desktop pet. Identity must survive multiple actions and directions, frames need compatible structure and transparency, and the final package must remain installable after the production context is removed. OmniPet treats that gap as a product workflow rather than a single prompt.

## Engine capability

OmniPet is an open-source Python engine and CLI for sprite v2 production. Manifest-driven projects and resumable state let work advance one bounded step at a time: the engine persists a failed generation instead of retrying automatically, requires explicit human approval, and can repair a selected job while preserving unaffected upstream work. The shipped extension axes are versioned manifests, action definitions, bounded engine APIs, validators, approval state, and a closed release schema. The current engine isolates one allowlisted built-in image provider and does not expose arbitrary provider or model configuration.

</section>

## 产品问题

一张令人信服的生成图还不是桌宠。角色身份需要跨越多种动作与方向，各帧要具备兼容的结构和透明度，最终安装包也必须在脱离生产上下文后继续成立。OmniPet 将这段差距设计成产品工作流，而不是一次提示词调用。

## 引擎能力

OmniPet 是面向 sprite v2 生产的开源 Python 引擎与 CLI。清单驱动的项目和可恢复状态让工作每次只推进一个有界步骤：引擎会记录失败而不是自动重试，要求显式人工批准，并能修复指定任务而保留不受影响的上游成果。已交付的扩展轴包括带版本的清单、动作定义、有界引擎 API、验证器、批准状态与闭集发布结构。当前引擎仅隔离一个白名单内置图像 provider，不开放任意 provider 或模型配置。

## User value

Creators can stop, inspect, approve, repair, and resume without treating every failure as a restart. Export then produces a closed, allowlisted bundle whose declared files are bound by SHA-256 and can be verified independently without generation credentials.

## Public result

SuShi v1.0.1 is the current installable sprite v2 example in the public OmniPets catalog. It demonstrates the intended separation: visitors receive a documented, licensed, verifiable pet release, while production context stays with its creator. OmniPet remains Alpha software; interfaces may change, generated results still require review, and a broader community contribution workflow is not presented as shipped.

</section>

<section lang="zh-CN" data-locale-content="zh">

## 用户价值

创作者可以暂停、检查、批准、修复和继续，而不必把每次失败都当作从头开始。导出流程随后生成闭集白名单包，每个声明文件均由 SHA-256 绑定，并可在不使用生成凭据的情况下独立验证。

## 公开结果

SuShi v1.0.1 是 OmniPets 公共目录中当前可安装的 sprite v2 示例。它验证了这套分离：访客获得带说明、许可且可验证的桌宠发布，生产上下文则保留在创作者一侧。OmniPet 仍处于 Alpha 阶段，接口可能变化，生成结果仍需检查；更广泛的社区贡献工作流不会被描述为已交付功能。

</section>
